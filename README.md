A wrapper around `ssh`: pick a host with fzf, jump straight back to the last
one, keep a history of your connections.

```console
$ sshrek ls -r
HOST        LAST         COUNT  TOTAL  TARGET
nas         18m ago         2×     5m  192.168.1.9
staging     55m ago         3×    54m  deploy@staging.example.com:2222
prod-db     2h ago          6×  4h 6m  deploy@10.0.4.12
jump        never           0×     0s  ops@jump.example.com
old-laptop  3 weeks ago     1×     7m  (not in config)
```

- **`sshrek`** opens `~/.ssh/config` in fzf, every host carrying its last
  connection, its count and where it actually points.
- **`sshrek -`** goes back to the host you used last — nothing to remember and
  nothing to type.
- Sessions are appended to a plain JSONL file, which is what lets the list sort
  by recency or by frequency. It is yours to grep.
- `ssh` is still underneath: `sshrek prod-db -- -L 8080:localhost:80`.

## Install

```sh
brew install Zhurik/tap/sshrek
```

The tap covers macOS on Apple silicon and Intel, and Linux on x86_64 and arm64.
Otherwise take the archive for your platform from
[Releases](https://github.com/Zhurik/sshrek/releases/latest) and drop the binary
into your `PATH`, or build it yourself:

```sh
cargo install --path .
```

macOS and Linux are supported. The picker is `fzf` by default, so install that
too — or [point sshrek at another one](docs/configuration.md).

## The commands you will actually type

| Command | What it does |
|---|---|
| `sshrek` | pick a host from `~/.ssh/config` with fzf |
| `sshrek -` | connect to the last host |
| `sshrek <host>` | connect directly |
| `sshrek <host> -- <ssh args>` | everything after `--` goes to `ssh` |
| `sshrek ls -r` | table of hosts and history, most recent first |

Inside the picker: `ctrl-o` — config order, `ctrl-r` — most recent first,
`ctrl-f` — most frequent first.
