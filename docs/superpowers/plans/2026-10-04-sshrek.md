# sshrek Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать `sshrek` — обёртку над `ssh`, которая выбирает хост через внешний fzf, мгновенно возвращает к последнему хосту по `sshrek -` и ведёт историю подключений.

**Architecture:** Поток данных линейный: `~/.ssh/config` парсится в `Vec<HostEntry>`, append-only JSONL-лог сворачивается в `HashMap<String, HostStats>`, оба попадают в сортировку и рендер, строки уходят внешнему пикеру, выбранный алиас — в `runner`, который пишет пару событий `start`/`end` вокруг запуска `ssh`. Все внешние точки (путь к конфигу, каталог состояния, бинарник ssh, команда пикера) читаются из env, поэтому каждый модуль тестируется в одиночку.

**Tech Stack:** Rust 2021, clap 4 (derive), serde/serde_json, chrono, anyhow, shell-words, glob, libc; тесты — assert_cmd, predicates, tempfile.

**Spec:** `docs/superpowers/specs/2026-10-04-sshrek-design.md`

## Global Constraints

- Имя крейта и бинарника — `sshrek`; edition `2021`; `rust-version = "1.82"`.
- Платформа только Unix (macOS и Linux). Windows не поддерживается.
- Никаких C-зависимостей, кроме `libc` — это условие статической сборки под musl в Task 11.
- Все сообщения об ошибках: в stderr, одной строкой, с префиксом `sshrek: `, на русском, без backtrace.
- История никогда не причина падения: ошибка чтения или записи лога → предупреждение в stderr, подключение всё равно происходит.
- `~/.ssh/config` только читается, никогда не пишется.
- Коды выхода: код `ssh` прокидывается как есть; 0 — успех служебных команд; 1 — ошибка `sshrek`; 130 — отмена выбора.
- Схема лога: `SCHEMA_VERSION = 1`; строки с другой `v` пропускаются, битые строки пропускаются.
- `cargo clippy --all-targets -- -D warnings` и `cargo fmt --check` должны быть чисты после каждой задачи.
- `Cargo.lock` коммитится: релизная сборка идёт с `--locked`.

## Review Focus

Пять классов входных данных, которые спека подразумевает, но не описывает явно. Для каждого ниже указано, в какой задаче живёт пиннингующий тест.

1. **`end.at` раньше `start.at`** (часы подвинул NTP или ручная правка лога) — длительность должна стать нулём, а не паниковать на вычитании и не уходить в минус. → Task 5.
2. **Запуск не в терминале** (`sshrek` в пайпе, из скрипта, из cron) — fzf без TTY выходит с кодом 2; нужно внятное сообщение с подсказкой `sshrek <host>`, а не «пикер завершился с кодом 2». → Task 8.
3. **`-r` и `-f` одновременно** — взаимоисключающие флаги должны давать ошибку clap, а не молча выбирать один. → Task 10.
4. **`~/.ssh/config` с CRLF и без завершающего перевода строки** — последний `Host` не должен ни теряться, ни получать `\r` в алиас. → Task 3.
5. **`SSHREK_STATE_DIR` указывает на существующий файл** (или каталог без прав на запись) — `append` обязан вернуть ошибку, которая превращается в предупреждение, а подключение всё равно состояться. → Task 4 (юнит) и Task 10 (интеграционный).

```rust
use std::path::{Path, PathBuf};

pub const LOG_FILE: &str = "sessions.jsonl";

fn non_empty(v: Option<&str>) -> Option<&str> {
    v.map(str::trim).filter(|s| !s.is_empty())
}

pub fn resolve_ssh_config(env_val: Option<&str>, home: &Path) -> PathBuf {
    match non_empty(env_val) {
        Some(v) => PathBuf::from(v),
        None => home.join(".ssh").join("config"),
    }
}

pub fn resolve_state_dir(sshrek_dir: Option<&str>, xdg: Option<&str>, home: &Path) -> PathBuf {
    if let Some(v) = non_empty(sshrek_dir) {
        return PathBuf::from(v);
    }
    if let Some(v) = non_empty(xdg) {
        return PathBuf::from(v).join("sshrek");
    }
    home.join(".local").join("state").join("sshrek")
}

fn home() -> PathBuf {
    std::env::var_os("HOME")
        .map(PathBuf::from)
        .unwrap_or_else(|| PathBuf::from("."))
}

pub fn ssh_config() -> PathBuf {
    let env_val = std::env::var("SSHREK_SSH_CONFIG").ok();
    resolve_ssh_config(env_val.as_deref(), &home())
}

pub fn state_dir() -> PathBuf {
    let own = std::env::var("SSHREK_STATE_DIR").ok();
    let xdg = std::env::var("XDG_STATE_HOME").ok();
    resolve_state_dir(own.as_deref(), xdg.as_deref(), &home())
}

pub fn sessions_log() -> PathBuf {
    state_dir().join(LOG_FILE)
}
```

Дописать в начало `src/config.rs`:

```rust
use std::collections::HashSet;
use std::path::{Path, PathBuf};

const MAX_INCLUDE_DEPTH: usize = 16;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct HostEntry {
    pub alias: String,
    pub hostname: Option<String>,
    pub user: Option<String>,
    pub port: Option<u16>,
    pub order: usize,
}

pub fn parse_file(path: &Path) -> Vec<HostEntry> {
    let Ok(src) = std::fs::read_to_string(path) else {
        return Vec::new();
    };
    let mut p = Parser::default();
    p.visited
        .insert(path.canonicalize().unwrap_or_else(|_| path.to_path_buf()));
    let base = path.parent().unwrap_or(Path::new(".")).to_path_buf();
    p.feed(&src, &base, 0);
    p.entries
}

#[derive(Default)]
struct Parser {
    entries: Vec<HostEntry>,
    seen: HashSet<String>,
    visited: HashSet<PathBuf>,
    order: usize,
}

impl Parser {
    fn feed(&mut self, src: &str, base: &Path, depth: usize) {
        // Индексы entries, объявленных текущим блоком Host: опции применяются ко всем.
        let mut block: Vec<usize> = Vec::new();
        // Внутри блока Match: его условия вычисляются при подключении,
        // статического списка хостов из них не получить.
        let mut skipping = false;

        for raw in src.lines() {
            let line = raw.trim();
            if line.is_empty() || line.starts_with('#') {
                continue;
            }
            let Some((kw, rest)) = split_keyword(line) else {
                continue;
            };
            match kw.as_str() {
                "host" => {
                    skipping = false;
                    block.clear();
                    for tok in rest.split_whitespace() {
                        let alias = unquote(tok);
                        if alias.is_empty() || is_pattern(&alias) {
                            continue;
                        }
                        if !self.seen.insert(alias.clone()) {
                            continue;
                        }
                        self.entries.push(HostEntry {
                            alias,
                            hostname: None,
                            user: None,
                            port: None,
                            order: self.order,
                        });
                        self.order += 1;
                        block.push(self.entries.len() - 1);
                    }
                }
                "match" => {
                    skipping = true;
                    block.clear();
                }
                "include" if !skipping => {
                    if depth >= MAX_INCLUDE_DEPTH {
                        continue;
                    }
                    let patterns: Vec<String> =
                        rest.split_whitespace().map(unquote).collect();
                    for pattern in patterns {
                        self.include(&pattern, base, depth);
                    }
                }
                "hostname" | "user" | "port" if !skipping => {
                    let val = unquote(rest.trim());
                    for &i in &block {
                        let e = &mut self.entries[i];
                        match kw.as_str() {
                            "hostname" => {
                                if e.hostname.is_none() {
                                    e.hostname = Some(val.clone());
                                }
                            }
                            "user" => {
                                if e.user.is_none() {
                                    e.user = Some(val.clone());
                                }
                            }
                            _ => {
                                if e.port.is_none() {
                                    e.port = val.parse().ok();
                                }
                            }
                        }
                    }
                }
                _ => {}
            }
        }
    }

    fn include(&mut self, pattern: &str, base: &Path, depth: usize) {
        let expanded = expand_path(pattern, base);
        let Ok(paths) = glob::glob(&expanded.to_string_lossy()) else {
            return;
        };
        let mut found: Vec<PathBuf> = paths.flatten().collect();
        found.sort();
        for path in found {
            let canon = path.canonicalize().unwrap_or_else(|_| path.clone());
            if !self.visited.insert(canon) {
                continue;
            }
            let Ok(src) = std::fs::read_to_string(&path) else {
                continue;
            };
            let next_base = path
                .parent()
                .map(Path::to_path_buf)
                .unwrap_or_else(|| base.to_path_buf());
            self.feed(&src, &next_base, depth + 1);
        }
    }
}

fn split_keyword(line: &str) -> Option<(String, String)> {
    let mut end = line.len();
    for (i, c) in line.char_indices() {
        if c.is_whitespace() || c == '=' {
            end = i;
            break;
        }
    }
    if end == 0 {
        return None;
    }
    let kw = line[..end].to_ascii_lowercase();
    let rest = line[end..]
        .trim_start_matches(|c: char| c.is_whitespace() || c == '=')
        .to_string();
    Some((kw, rest))
}

fn unquote(s: &str) -> String {
    let t = s.trim();
    if t.len() >= 2 && t.starts_with('"') && t.ends_with('"') {
        t[1..t.len() - 1].to_string()
    } else {
        t.to_string()
    }
}

fn is_pattern(alias: &str) -> bool {
    alias.contains('*') || alias.contains('?') || alias.starts_with('!')
}

fn expand_path(p: &str, base: &Path) -> PathBuf {
    if let Some(rest) = p.strip_prefix("~/") {
        if let Some(home) = std::env::var_os("HOME") {
            return PathBuf::from(home).join(rest);
        }
    }
    let path = Path::new(p);
    if path.is_absolute() {
        path.to_path_buf()
    } else {
        base.join(path)
    }
}
```

Обрати внимание: `unquote` принимает `&str` и возвращает `String`, поэтому в ветке
`"include"` паттерны сначала собираются в `Vec<String>` — иначе итератор по `rest`
держал бы заимствование, пока `self.include` требует `&mut self`.

```rust
use std::time::SystemTime;

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};

pub const SCHEMA_VERSION: u32 = 1;

pub type SessionId = String;

/// `<наносекунды в hex>-<pid в hex>`: уникально без генератора UUID и читаемо глазами.
pub fn new_session_id(now: SystemTime, pid: u32) -> SessionId {
    let nanos = now
        .duration_since(SystemTime::UNIX_EPOCH)
        .map(|d| d.as_nanos())
        .unwrap_or(0);
    format!("{nanos:x}-{pid:x}")
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "event", rename_all = "lowercase")]
pub enum Event {
    Start {
        id: SessionId,
        host: String,
        at: DateTime<Utc>,
        #[serde(default, skip_serializing_if = "Vec::is_empty")]
        args: Vec<String>,
    },
    End {
        id: SessionId,
        at: DateTime<Utc>,
        exit: Option<i32>,
        #[serde(default, skip_serializing_if = "Option::is_none")]
        error: Option<String>,
    },
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Record {
    pub v: u32,
    #[serde(flatten)]
    pub event: Event,
}

impl Record {
    pub fn start(id: SessionId, host: &str, at: DateTime<Utc>, args: &[String]) -> Self {
        Record {
            v: SCHEMA_VERSION,
            event: Event::Start {
                id,
                host: host.to_string(),
                at,
                args: args.to_vec(),
            },
        }
    }

    pub fn end(id: SessionId, at: DateTime<Utc>, exit: Option<i32>, error: Option<String>) -> Self {
        Record {
            v: SCHEMA_VERSION,
            event: Event::End {
                id,
                at,
                exit,
                error,
            },
        }
    }
}

#[derive(Debug)]
pub enum LineOutcome {
    Parsed(Record),
    UnknownVersion,
    Malformed,
}

/// Сначала смотрим только на `v`: строка будущей схемы должна пропускаться,
/// а не считаться битой.
pub fn parse_line(line: &str) -> LineOutcome {
    let Ok(value) = serde_json::from_str::<serde_json::Value>(line) else {
        return LineOutcome::Malformed;
    };
    match value.get("v").and_then(serde_json::Value::as_u64) {
        Some(v) if v == u64::from(SCHEMA_VERSION) => {}
        Some(_) => return LineOutcome::UnknownVersion,
        None => return LineOutcome::Malformed,
    }
    match serde_json::from_value::<Record>(value) {
        Ok(rec) => LineOutcome::Parsed(rec),
        Err(_) => LineOutcome::Malformed,
    }
}
```

```rust
use std::fs::OpenOptions;
use std::io::Write;
use std::path::PathBuf;

use anyhow::{Context, Result};

use super::event::{parse_line, LineOutcome, Record};

pub struct Store {
    path: PathBuf,
}

#[derive(Debug, Default)]
pub struct ReadResult {
    pub records: Vec<Record>,
    pub malformed: usize,
    pub unknown_version: usize,
    pub error: Option<String>,
}

impl Store {
    pub fn new(path: PathBuf) -> Self {
        Store { path }
    }

    /// Append-only: одна запись — одна строка, файл никогда не перезаписывается.
    pub fn append(&self, rec: &Record) -> Result<()> {
        if let Some(parent) = self.path.parent() {
            std::fs::create_dir_all(parent)
                .with_context(|| format!("не удалось создать {}", parent.display()))?;
        }
        let line = serde_json::to_string(rec).context("сериализация события")?;
        let mut file = OpenOptions::new()
            .create(true)
            .append(true)
            .open(&self.path)
            .with_context(|| format!("не удалось открыть {}", self.path.display()))?;
        file.write_all(line.as_bytes())
            .and_then(|()| file.write_all(b"\n"))
            .with_context(|| format!("не удалось записать в {}", self.path.display()))
    }

    /// Никогда не возвращает Err: по спеке история не причина падения.
    pub fn read_all(&self) -> ReadResult {
        let mut out = ReadResult::default();
        let text = match std::fs::read_to_string(&self.path) {
            Ok(t) => t,
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => return out,
            Err(e) => {
                out.error = Some(format!("{}: {e}", self.path.display()));
                return out;
            }
        };
        for line in text.lines() {
            if line.trim().is_empty() {
                continue;
            }
            match parse_line(line) {
                LineOutcome::Parsed(rec) => out.records.push(rec),
                LineOutcome::UnknownVersion => out.unknown_version += 1,
                LineOutcome::Malformed => out.malformed += 1,
            }
        }
        out
    }
}
```

```rust
use std::collections::HashMap;

use chrono::{DateTime, TimeDelta, Utc};

use super::event::{Event, Record};

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct HostStats {
    pub host: String,
    pub connections: u32,
    pub last_connected: Option<DateTime<Utc>>,
    pub total_duration: TimeDelta,
    pub last_duration: Option<TimeDelta>,
    pub failures: u32,
    pub unfinished: u32,
}

impl HostStats {
    fn new(host: &str) -> Self {
        HostStats {
            host: host.to_string(),
            connections: 0,
            last_connected: None,
            total_duration: TimeDelta::zero(),
            last_duration: None,
            failures: 0,
            unfinished: 0,
        }
    }
}

pub fn aggregate(records: &[Record]) -> HashMap<String, HostStats> {
    let mut out: HashMap<String, HostStats> = HashMap::new();
    // id -> (хост, момент старта); закрытые сессии удаляются, остаток — незавершённые.
    let mut open: HashMap<&str, (&str, DateTime<Utc>)> = HashMap::new();

    for rec in records {
        match &rec.event {
            Event::Start { id, host, at, .. } => {
                let s = out
                    .entry(host.clone())
                    .or_insert_with(|| HostStats::new(host));
                s.connections += 1;
                if s.last_connected.is_none_or(|prev| *at > prev) {
                    s.last_connected = Some(*at);
                }
                open.insert(id.as_str(), (host.as_str(), *at));
            }
            Event::End {
                id, at, exit, error, ..
            } => {
                let Some((host, started)) = open.remove(id.as_str()) else {
                    continue;
                };
                let s = out
                    .entry(host.to_string())
                    .or_insert_with(|| HostStats::new(host));
                // Часы могли уехать назад: отрицательная длительность — это ноль.
                let raw = *at - started;
                let d = if raw < TimeDelta::zero() {
                    TimeDelta::zero()
                } else {
                    raw
                };
                s.total_duration += d;
                s.last_duration = Some(d);
                if error.is_some() || exit.is_some_and(|c| c != 0) {
                    s.failures += 1;
                }
            }
        }
    }

    for (host, _started) in open.into_values() {
        if let Some(s) = out.get_mut(host) {
            s.unfinished += 1;
        }
    }
    out
}

pub fn last_host(records: &[Record]) -> Option<&str> {
    records.iter().rev().find_map(|r| match &r.event {
        Event::Start { host, .. } => Some(host.as_str()),
        Event::End { .. } => None,
    })
}
```

```rust
use std::cmp::Ordering;
use std::collections::HashMap;

use chrono::{DateTime, Utc};

use crate::config::HostEntry;
use crate::history::HostStats;

#[derive(Debug, Clone, Copy, PartialEq, Eq, clap::ValueEnum)]
#[value(rename_all = "lower")]
pub enum SortKey {
    /// Порядок объявления в ~/.ssh/config
    Config,
    /// Свежие подключения сверху
    Recent,
    /// Частые подключения сверху
    Frequent,
}

fn last_of(stats: &HashMap<String, HostStats>, alias: &str) -> Option<DateTime<Utc>> {
    stats.get(alias).and_then(|s| s.last_connected)
}

fn count_of(stats: &HashMap<String, HostStats>, alias: &str) -> u32 {
    stats.get(alias).map_or(0, |s| s.connections)
}

pub fn sort_hosts(hosts: &mut [HostEntry], stats: &HashMap<String, HostStats>, key: SortKey) {
    match key {
        SortKey::Config => hosts.sort_by_key(|h| h.order),
        SortKey::Recent => hosts.sort_by(|a, b| {
            match (last_of(stats, &a.alias), last_of(stats, &b.alias)) {
                (Some(x), Some(y)) => y.cmp(&x).then(a.order.cmp(&b.order)),
                (Some(_), None) => Ordering::Less,
                (None, Some(_)) => Ordering::Greater,
                (None, None) => a.order.cmp(&b.order),
            }
        }),
        SortKey::Frequent => hosts.sort_by(|a, b| {
            count_of(stats, &b.alias)
                .cmp(&count_of(stats, &a.alias))
                .then_with(|| last_of(stats, &b.alias).cmp(&last_of(stats, &a.alias)))
                .then(a.order.cmp(&b.order))
        }),
    }
}
```

```rust
use chrono::{DateTime, TimeDelta, Utc};

use crate::config::HostEntry;
use crate::history::HostStats;

/// Кэп ширины колонки: длинное значение расширит свою строку,
/// но не растянет таблицу целиком.
const MAX_ALIAS_WIDTH: usize = 24;
const MAX_LAST_WIDTH: usize = 16;
const MAX_COUNT_WIDTH: usize = 8;

pub fn fmt_relative(then: DateTime<Utc>, now: DateTime<Utc>) -> String {
    let secs = (now - then).num_seconds();
    if secs < 60 {
        return "just now".to_string();
    }
    let mins = secs / 60;
    if mins < 60 {
        return format!("{mins}m ago");
    }
    let hours = mins / 60;
    if hours < 24 {
        return format!("{hours}h ago");
    }
    let days = hours / 24;
    if days < 7 {
        return if days == 1 {
            "1 day ago".to_string()
        } else {
            format!("{days} days ago")
        };
    }
    let weeks = days / 7;
    if days < 30 {
        return if weeks == 1 {
            "1 week ago".to_string()
        } else {
            format!("{weeks} weeks ago")
        };
    }
    let months = days / 30;
    if months < 12 {
        return format!("{months} months ago");
    }
    let years = days / 365;
    if years <= 1 {
        "1 year ago".to_string()
    } else {
        format!("{years} years ago")
    }
}

pub fn fmt_duration(d: TimeDelta) -> String {
    let s = d.num_seconds();
    if s <= 0 {
        return "0s".to_string();
    }
    let (h, m) = (s / 3600, (s % 3600) / 60);
    if h > 0 {
        format!("{h}h {m}m")
    } else if m > 0 {
        format!("{m}m")
    } else {
        format!("{s}s")
    }
}

pub fn target_of(e: &HostEntry) -> String {
    let host = e.hostname.clone().unwrap_or_else(|| e.alias.clone());
    let mut t = match &e.user {
        Some(u) => format!("{u}@{host}"),
        None => host,
    };
    if let Some(p) = e.port {
        if p != 22 {
            t.push_str(&format!(":{p}"));
        }
    }
    t
}

struct Cells {

    last: String,
    count: String,
    total: String,
    target: String,
}

        .iter()
        .map(|h| {

            Cells {

                last: st
                    .and_then(|s| s.last_connected)
                    .map_or_else(|| "never".to_string(), |t| fmt_relative(t, now)),
                count: format!("{}×", st.map_or(0, |s| s.connections)),
                total: st.map_or_else(
                    || "0s".to_string(),
                    |s| fmt_duration(s.total_duration),
                ),
                target: target_of(h),
            }
        })
        .collect()
}

pub fn ls_table(
    hosts: &[HostEntry],
    stats: &HashMap<String, HostStats>,
    orphans: &[&HostStats],
    now: DateTime<Utc>,
) -> String {
    let mut cells = cells_for(hosts, stats, now);
    for s in orphans {
        cells.push(Cells {
            alias: s.host.clone(),
            last: s
                .last_connected
                .map_or_else(|| "never".to_string(), |t| fmt_relative(t, now)),
            count: format!("{}×", s.connections),
            total: fmt_duration(s.total_duration),
            target: "(нет в config)".to_string(),
        });
    }

    let header = Cells {
        alias: "HOST".into(),
        last: "LAST".into(),
        count: "COUNT".into(),
        total: "TOTAL".into(),
        target: "TARGET".into(),
    };
    let all: Vec<&Cells> = std::iter::once(&header).chain(cells.iter()).collect();
    let wa = width(all.iter().map(|c| c.alias.chars().count()), MAX_ALIAS_WIDTH);
    let wl = width(all.iter().map(|c| c.last.chars().count()), MAX_LAST_WIDTH);
    let wc = width(all.iter().map(|c| c.count.chars().count()), MAX_COUNT_WIDTH);
    let wt = width(all.iter().map(|c| c.total.chars().count()), 12);

    all.iter()
        .map(|c| {
            format!(
                "{:<wa$}  {:<wl$}  {:>wc$}  {:>wt$}  {}",
                c.alias,
                c.last,
                c.count,
                c.total,
                c.target,
                wa = wa,
                wl = wl,
                wc = wc,
                wt = wt
            )
            .trim_end()
            .to_string()
        })
        .collect::<Vec<_>>()
        .join("\n")
}

pub fn preview(
    alias: &str,
    entry: Option<&HostEntry>,
    stats: Option<&HostStats>,
    now: DateTime<Utc>,
) -> String {
    let target = entry.map_or_else(|| "(нет в config)".to_string(), target_of);
    let last = stats.and_then(|s| s.last_connected).map_or_else(
        || "never".to_string(),

            let rel = fmt_relative(t, now);
            match stats.and_then(|s| s.last_duration) {
                Some(d) => format!("{rel} ({})", fmt_duration(d)),
                None => rel,
            }
        },
    );
    let connections = stats.map_or(0, |s| s.connections);
    let total = stats.map_or_else(|| "0s".to_string(), |s| fmt_duration(s.total_duration));
    let failures = stats.map_or(0, |s| s.failures);
    let unfinished = stats.map_or(0, |s| s.unfinished);

    let mut out = format!(
        "{alias}\n  target       {target}\n  connections  {connections}\n  last         {last}\n  total        {total}\n"
    );
    if failures > 0 {
        out.push_str(&format!("  failures     {failures}\n"));
    }
    if unfinished > 0 {
        out.push_str(&format!("  unfinished   {unfinished}\n"));
    }
    out
```

```rust
use std::io::Write;
use std::process::{Command, Stdio};

use anyhow::{bail, Context, Result};

pub const DEFAULT_PICKER: &str = "fzf";

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PickerCmd {
    pub program: String,
    pub args: Vec<String>,
}

#[derive(Debug)]
pub enum PickOutcome {
    Selected(String),
    Cancelled,
}

/// Флаги для fzf. `fzf-tmux` незнакомые ему аргументы передаёт в fzf,
/// поэтому `SSHREK_PICKER='fzf-tmux -p'` работает с тем же набором.
pub fn default_args(self_exe: &str) -> Vec<String> {
    let me = shell_words::quote(self_exe).to_string();
    vec![
        "--no-sort".to_string(),
        "--layout=reverse".to_string(),
        "--height=40%".to_string(),
        "--prompt".to_string(),
        "ssh > ".to_string(),
        "--preview".to_string(),
        format!("{me} preview {{1}}"),
        "--preview-window".to_string(),
        "right,45%,border-left".to_string(),
        "--header".to_string(),
        "ctrl-o config · ctrl-r recent · ctrl-f frequent".to_string(),
        "--bind".to_string(),
        format!("ctrl-o:reload({me} ls --porcelain --picker --sort=config)"),
        "--bind".to_string(),
        format!("ctrl-r:reload({me} ls --porcelain --picker --sort=recent)"),
        "--bind".to_string(),
        format!("ctrl-f:reload({me} ls --porcelain --picker --sort=frequent)"),
    ]
}

fn non_empty(v: Option<&str>) -> Option<&str> {
    v.map(str::trim).filter(|s| !s.is_empty())
}

pub fn build_command(
    picker_env: Option<&str>,
    args_env: Option<&str>,
    self_exe: &str,
) -> Result<PickerCmd> {
    let spec = non_empty(picker_env).unwrap_or(DEFAULT_PICKER);
    let mut words =
        shell_words::split(spec).context("SSHREK_PICKER не разбирается как команда шелла")?;
    if words.is_empty() {
        bail!("SSHREK_PICKER пуст");
    }
    let program = words.remove(0);
    let mut args = words;
    match non_empty(args_env) {
        Some(custom) => args.extend(
            shell_words::split(custom)
                .context("SSHREK_PICKER_ARGS не разбирается как аргументы шелла")?,
        ),
        None => args.extend(default_args(self_exe)),
    }
    Ok(PickerCmd { program, args })
}

pub fn run(cmd: &PickerCmd, rows: &[String]) -> Result<PickOutcome> {
    let mut child = Command::new(&cmd.program)
        .args(&cmd.args)
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .spawn()
        .with_context(|| {
            format!(
                "не удалось запустить пикер '{}' (задаётся через SSHREK_PICKER)",
                cmd.program
            )
        })?;

    {
        let mut stdin = child.stdin.take().expect("stdin запрошен как piped");
        // Пикер мог закрыться раньше, чем мы дописали строки: EPIPE здесь
        // не ошибка, настоящий вердикт — код выхода.
        for row in rows {
            if writeln!(stdin, "{row}").is_err() {
                break;
            }
        }
    }

    let out = child
        .wait_with_output()
        .with_context(|| format!("пикер '{}' не завершился корректно", cmd.program))?;

    match out.status.code() {
        Some(0) => {
            let text = String::from_utf8_lossy(&out.stdout);
            let alias = text
                .lines()
                .next()
                .unwrap_or("")
                .split_whitespace()
                .next()
                .unwrap_or("");
            if alias.is_empty() {
                Ok(PickOutcome::Cancelled)
            } else {
                Ok(PickOutcome::Selected(alias.to_string()))
            }
        }
        // 130 — Esc/Ctrl-C, 1 — ничего не нашлось: для нас это одно и то же.
        Some(130) | Some(1) => Ok(PickOutcome::Cancelled),
        Some(code) => bail!(
            "пикер '{}' завершился с кодом {code}; для выбора нужен терминал — если запускаешь не в нём, укажи хост явно: sshrek <host>",
            cmd.program
        ),
        None => Ok(PickOutcome::Cancelled),
    }
}
```

```rust
use std::process::Command;
use std::time::SystemTime;

use chrono::Utc;

use crate::history::{new_session_id, Record, Store};

/// На время ожидания ssh родитель перестаёт умирать от Ctrl-C: иначе
/// end-событие не запишется и сессия навсегда останется незавершённой.
/// Сам ssh свой SIGINT получает как обычно — он в той же foreground-группе.
struct SignalGuard {
    int: libc::sighandler_t,
    quit: libc::sighandler_t,
}

impl SignalGuard {
    fn ignore_interrupts() -> Self {
        unsafe {
            SignalGuard {
                int: libc::signal(libc::SIGINT, libc::SIG_IGN),
                quit: libc::signal(libc::SIGQUIT, libc::SIG_IGN),
            }
        }
    }
}

impl Drop for SignalGuard {
    fn drop(&mut self) {
        unsafe {
            libc::signal(libc::SIGINT, self.int);
            libc::signal(libc::SIGQUIT, self.quit);
        }
    }
}

fn warn_on_err(result: anyhow::Result<()>) {
    if let Err(e) = result {
        eprintln!("sshrek: история не записана: {e}");
    }
}

pub fn connect(store: &Store, ssh_bin: &str, host: &str, extra: &[String]) -> i32 {
    let id = new_session_id(SystemTime::now(), std::process::id());
    warn_on_err(store.append(&Record::start(id.clone(), host, Utc::now(), extra)));

    let status = {
        let _guard = SignalGuard::ignore_interrupts();
        Command::new(ssh_bin).arg(host).args(extra).status()
    };

    match status {
        Ok(st) => {
            let code = exit_code_of(&st);
            warn_on_err(store.append(&Record::end(id, Utc::now(), Some(code), None)));
            code
        }
        Err(e) => {
            eprintln!("sshrek: не удалось запустить '{ssh_bin}' (см. SSHREK_SSH_BIN): {e}");
            warn_on_err(store.append(&Record::end(
                id,
                Utc::now(),
                None,
                Some(e.to_string()),
            )));
            1
        }
    }
}

fn exit_code_of(status: &std::process::ExitStatus) -> i32 {
    use std::os::unix::process::ExitStatusExt;
    status
        .code()
        .unwrap_or_else(|| 128 + status.signal().unwrap_or(0))
}
```

```rust
mod cli;
mod config;
mod history;
mod paths;
mod picker;
mod render;
mod runner;
mod sort;

use std::collections::HashMap;

use chrono::Utc;
use clap::{CommandFactory, Parser};

use cli::{Cli, Command};
use config::HostEntry;
use history::{HostStats, Store};
use picker::PickOutcome;
use sort::SortKey;

fn main() {
    let args = Cli::parse();
    std::process::exit(run(args));
}

struct Context {
    hosts: Vec<HostEntry>,
    stats: HashMap<String, HostStats>,
    store: Store,
    /// Последний start-эвент: считается здесь же, чтобы не читать лог второй раз.
    last_host: Option<String>,
}

fn load(verbose: bool) -> Context {
    let hosts = config::parse_file(&paths::ssh_config());
    let store = Store::new(paths::sessions_log());
    let read = store.read_all();
    if verbose {
        if let Some(e) = &read.error {
            eprintln!("sshrek: история не прочитана: {e}");
        }
        if read.malformed > 0 || read.unknown_version > 0 {
            eprintln!(
                "sshrek: в логе пропущено строк: битых {}, с другой версией схемы {}",
                read.malformed, read.unknown_version
            );
        }
    }
    let stats = history::aggregate(&read.records);
    let last_host = history::last_host(&read.records).map(str::to_string);
    Context {
        hosts,
        stats,
        store,
        last_host,
    }
}

fn ssh_bin() -> String {
    std::env::var("SSHREK_SSH_BIN")
        .ok()
        .map(|v| v.trim().to_string())
        .filter(|v| !v.is_empty())
        .unwrap_or_else(|| "ssh".to_string())
}

fn sorted_hosts(ctx: &Context, key: SortKey) -> Vec<HostEntry> {
    let mut hosts = ctx.hosts.clone();
    sort::sort_hosts(&mut hosts, &ctx.stats, key);
    hosts
}

/// Хосты, которые есть в истории, но исчезли из config: подключиться к ним
/// нельзя, но в `ls` о них полезно знать.
fn orphans<'a>(ctx: &'a Context, hosts: &[HostEntry]) -> Vec<&'a HostStats> {
    let known: std::collections::HashSet<&str> =
        hosts.iter().map(|h| h.alias.as_str()).collect();
    let mut out: Vec<&HostStats> = ctx
        .stats
        .values()
        .filter(|s| !known.contains(s.host.as_str()))
        .collect();
    out.sort_by(|a, b| b.last_connected.cmp(&a.last_connected).then(a.host.cmp(&b.host)));
    out
}

fn run(args: Cli) -> i32 {
    match &args.command {
        Some(Command::Completions { shell }) => {
            let mut cmd = Cli::command();
            let name = cmd.get_name().to_string();
            clap_complete::generate(*shell, &mut cmd, name, &mut std::io::stdout());
            0
        }
        Some(Command::Preview { host }) => {
            let ctx = load(args.verbose);
            let entry = ctx.hosts.iter().find(|h| &h.alias == host);
            print!(
                "{}",
                render::preview(host, entry, ctx.stats.get(host), Utc::now())
            );
            0
        }
        Some(Command::Ls {
            porcelain,
            picker: picker_format,
            sorting,
        }) => {
            let ctx = load(args.verbose);
            let hosts = sorted_hosts(&ctx, sorting.key());
            let now = Utc::now();
            if *porcelain {
                let rows = if *picker_format {
                    render::picker_rows(&hosts, &ctx.stats, now)
                } else {
                    render::porcelain_rows(&hosts, &ctx.stats, now)
                };
                for row in rows {
                    println!("{row}");
                }
            } else {
                let gone = orphans(&ctx, &hosts);
                println!("{}", render::ls_table(&hosts, &ctx.stats, &gone, now));
            }
            0
        }
        None => connect_flow(&args),
    }
}

fn connect_flow(args: &Cli) -> i32 {
    let ctx = load(args.verbose);

    let host = match args.host.as_deref() {
        Some("-") => match ctx.last_host.clone() {
            Some(h) => h,
            None => {
                eprintln!("sshrek: истории пока нет, запусти sshrek без аргументов и выбери хост");
                return 1;
            }
        },
        Some(explicit) => explicit.to_string(),
        None => {
            let hosts = sorted_hosts(&ctx, args.sorting.key());
            if hosts.is_empty() {
                eprintln!(
                    "sshrek: в {} нет ни одного хоста",
                    paths::ssh_config().display()
                );
                return 1;
            }
            let rows = render::picker_rows(&hosts, &ctx.stats, Utc::now());
            let self_exe = std::env::current_exe()
                .map(|p| p.to_string_lossy().into_owned())
                .unwrap_or_else(|_| "sshrek".to_string());
            let picker_env = std::env::var("SSHREK_PICKER").ok();
            let args_env = std::env::var("SSHREK_PICKER_ARGS").ok();

            let cmd = match picker::build_command(
                picker_env.as_deref(),
                args_env.as_deref(),
                &self_exe,
            ) {
                Ok(c) => c,
                Err(e) => {
                    eprintln!("sshrek: {e}");
                    return 1;
                }
            };
            if args.verbose {
                eprintln!("sshrek: пикер {} {:?}", cmd.program, cmd.args);
            }
            match picker::run(&cmd, &rows) {
                Ok(PickOutcome::Selected(alias)) => alias,
                Ok(PickOutcome::Cancelled) => return 130,
                Err(e) => {
                    eprintln!("sshrek: {e}");
                    return 1;
                }
            }
        }
    };

    if args.verbose {
        eprintln!("sshrek: {} {} {:?}", ssh_bin(), host, args.extra);
    }
    runner::connect(&ctx.store, &ssh_bin(), &host, &args.extra)
}
```
